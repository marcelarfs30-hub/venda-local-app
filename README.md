# Venda Local com IA

Aplicativo web para ajudar autônomos e pequenos negócios a divulgarem seus serviços com mais consistência.

## Funcionalidades

- Gerador de legendas para Instagram
- Roteiros curtos para Reels
- Mensagens profissionais para WhatsApp
- Plano de divulgação em sete dias
- Botão de compartilhamento e suporte offline

## Demonstração

[Abrir o aplicativo](https://marcelarfs30-hub.github.io/venda-local-app/)

## Tecnologias

HTML, CSS e JavaScript, sem dependências externas.
